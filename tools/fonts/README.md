# Шрифты для значков языков

`ter-u*b_unicode.pcf` — Terminus Bold, растровый шрифт (SIL Open Font License 1.1),
из пакета Debian `xfonts-terminus`. Буквы в нём нарисованы по клеткам, штрих ровно
два пикселя — то же зерно, что у клавиатуры на значке, поэтому надпись не
приходится растрировать самим и она не плывёт от размера к размеру.

Цифра в имени — кегль: 28, 24 и 22. Генератор берёт самый крупный, который влезает
в отведённое место, поэтому длинные подписи автоматически идут мельче.
