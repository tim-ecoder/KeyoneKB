# Данные языковых пакетов

Как собраны файлы в `langpack/src/<язык>/assets`. Всё, кроме русского,
получено из открытых источников; русские словари — те же, что ехали в самой
клавиатуре до появления пакетов, пересортированные по частоте.

## Словари подсказок — `dictionaries/<язык>_base.txt`

Формат: `слово<TAB>вес`, вес 45–255 по логарифму частоты, строки по убыванию
частоты. Порядок важен: при уменьшенном размере словаря берутся первые N строк.

Источник: FrequencyWords (hermitdave), частотные списки OpenSubtitles 2018,
`content/2018/<lang>/<lang>_full.txt`. Фильтр — только буквы алфавита языка,
длина до 28 символов. Порог по частоте не ставится: французский даёт 612 тыс.
слов, немецкий 882 тыс., у русского 668 тыс.

## Биграммы — `dictionaries/<язык>_bigrams.json`

Топ-230 слов, у каждого 15 продолжений, вес 255…150 по рангу. Считаются по
корпусу Tatoeba (`downloads.tatoeba.org/exports/per_language/<lang>`). Нужны
для предсказания следующего слова.

## Перевод — `dict/<из>_<в>.tsv` и одноимённые `.cdb`

Формат TSV: `слово<TAB>перевод1,перевод2,...` (до 8 вариантов), строки по
убыванию частоты слова исходного языка.

Источники:
- WikDict (`download.wikdict.com/dictionaries/sqlite`), таблица
  `simple_translation` — леммы из Викисловаря;
- FreeDict: `deu-eng`/`eng-deu` (словарь Ding, 517 тыс. заголовков) — основной
  вклад в немецкий; французский там всего 8.5 тыс., поэтому почти не помогает;
- английский Викисловарь через kaikki.org (`kaikki.org/dictionary/French`) —
  даёт французские СЛОВОФОРМЫ: у формы нет своего толкования, ей раздаются
  переводы её леммы (`mangeais` -> `to eat`). Именно словоформы дают объём,
  как и в русском словаре, где склонения — отдельные статьи;
- AGID (`github.com/en-wl/wordlist`, `agid/infl.txt`, 3.4 МБ) — английские
  словоформы, тем же приёмом: `ate`, `houses`, `walking` получают переводы
  своей леммы. Извлечение английского Викисловаря весит 3.2 ГБ и ради этого
  не нужно.

`.cdb` — готовый индекс, который клавиатура маппит прямо из APK пакета
(zero-copy), поэтому перевод открывается сразу, без сборки словаря на
устройстве. Собирается `tools/build_cdb.c` — это тот же код `app/src/main/jni/cdb.c`,
что работает на телефоне, плюс повторение шагов `nativeBuildCdbFromTsv`
(сортировка по частоте исходного языка, запись всех записей):

    gcc -O2 -o build_cdb tools/build_cdb.c app/src/main/jni/cdb.c
    ./build_cdb fr_en.tsv fr_base.txt fr_en.cdb

Проверить содержимое: `gcc -O2 -o cdb_lookup tools/cdb_lookup.c app/src/main/jni/cdb.c`,
затем `./cdb_lookup fr_en.cdb maison clavier`.

ВАЖНО: `.cdb` обязан лежать в APK несжатым — за это отвечает
`aaptOptions { noCompress '.cdb' }` в `langpack/build.gradle`. Со сжатым файлом
`openFd` не работает и zero-copy пропадает.
