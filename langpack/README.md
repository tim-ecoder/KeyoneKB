# Языковые пакеты

Пакет — отдельное приложение без кода и без разрешений: только данные в
`assets` и значки. Клавиатура находит его через `PackageManager` по действию
`com.ai10.k12kb.LANGUAGE_PACK`, проверяет, что подпись совпадает с её
собственной, и читает файлы напрямую. Сети клавиатуре для этого не нужно.

Из одного модуля собирается матрица «язык × содержимое»: у каждого языка
получается четыре APK.

| Флейвор | Что везёт | Каталог исходников |
|---|---|---|
| `base` | раскладки, словарь текстом, биграммы, перевод, кеш на 35k | `src/<язык>Base/assets` |
| `idx150` | готовый кеш на 150 000 слов | `src/<язык>Idx150/assets/dictionaries` |
| `idx300` | готовый кеш на 300 000 слов | `src/<язык>Idx300/assets/dictionaries` |
| `idxfull` | готовый кеш по всему словарю | `src/<язык>Idxfull/assets/dictionaries` |

Значки лежат в `src/<язык>/res` — без суффикса содержимого, поэтому их видят
все четыре сборки языка.

Кеши крупных размеров в репозитории не хранятся (сотни мегабайт) — их собирает
`tools/build_indexes.sh`. Кеш на 35k внутри языкового пакета, наоборот,
отслеживается: без него сборка молча дала бы пакет, обещающий кеш и не везущий
его.

## Единственный список языков

`ext.packLanguages` в `langpack/build.gradle`. Оттуда берутся флейворы сборки,
версии, названия для каталога и коды языков для манифеста; `tools/*.py` и
`tools/build_indexes.sh` читают тот же список. Второго списка языков в проекте
нет намеренно — он неминуемо разошёлся бы с первым.

    it: [title: "Italiano", langs: "it", base: [code: 1, name: "1.0.0"],
                                          idx:  [code: 1, name: "1.0.0"]]

- `title` — название языка на экране «Языковые пакеты и словари»;
- `langs` — коды, которые пакет объявляет клавиатуре. Обычно один; несколько
  нужны, когда раскладка пользуется чужим словарём (украинская — русским);
- `base` и `idx` — версии по отдельности: кеш весит сотни мегабайт, и
  предлагать перекачивать его из-за правки в раскладке нельзя. Клавиатура
  сравнивает эти числа с `versionCode` установленного пакета и так узнаёт об
  обновлении, не выходя в сеть.

## Как добавить язык

1. **Запись в `packLanguages`** (см. выше).

2. **Данные** в `src/<язык>Base/assets` — форматы описаны в
   `tools/langpack-data.md`:
   - `dictionaries/<язык>_base.txt` — `слово<TAB>вес`, строки по убыванию
     частоты (при уменьшенном размере словаря берутся первые N строк);
   - `dictionaries/<язык>_bigrams.json` — предсказание следующего слова;
   - `dict/<из>_<в>.tsv` и `.cdb` — перевод; пары всегда через английский;
   - `bb_key_1_2/<раскладка>_hw.json` — сама раскладка;
   - `keyboard_layouts.json` — реестр раскладок пакета.

3. **Реестр раскладок.** Каждая запись обязана нести `"language"` — по нему
   выбирается словарь подсказок, направление перевода и значок в статус-баре.
   Угадывания по названию раскладки нет: имя у пакета произвольное.

       {
         "options-name": "Blackberry Key1|2 Italiano",
         "keyboard-mapping": "bb_key_1_2/italian_hw",
         "custom-keyboard-mechanics": "bb_key_1_2/keyboard_mechanics",
         "device-model-regexp": "(Blackberry (BBB|BBF|BBE|unknown).*)|(.*KEY2)",
         "language": "it"
       }

   Значки раскладки (`icon-lowercase`, `icon-first-shift`, `icon-capslock`) и
   `flag` необязательны: если их нет, клавиатура берёт заранее нарисованный
   значок по коду языка. Свой значок статус-бара пакет дать не может — система
   читает этот слот только из APK клавиатуры, поэтому значки на все коды ISO
   639-1 нарисованы заранее (`tools/make_lang_status_icons.py`).

4. **Значки пакета:** `python3 tools/make_icons.py .` — нарисует
   `src/<язык>/res` для всех языков из списка.

5. **Кеши:** `bash tools/build_indexes.sh` — соберёт 35k в `Base` и
   150k/300k/полный в `Idx*`. Скрипт останавливается, если данных нет или
   биграммы пустые.

6. **Сборка и каталог:**

       ./gradlew :langpack:assembleRelease
       python3 tools/make_pack_catalog.py

   Каталог пишется в `app/src/main/assets/language_packs.json` — по нему
   клавиатура показывает пакеты, их размер и наличие обновления. Размеры
   берутся из собранных APK, а `versionCode` сверяется с ними же: расхождение
   останавливает генератор. Для нового языка нужно добавить строку в `CONTENTS`
   внутри `tools/make_pack_catalog.py` — это единственный текст, которому
   неоткуда взяться самому.

7. **Клавиатуру пересобрать** — каталог лежит в её assets.

## Что стоит знать

- `.cdb` обязан лежать в APK несжатым (`aaptOptions { noCompress '.cdb' }`):
  клавиатура маппит его прямо из пакета. `.ssnd` так не читается — он
  распаковывается в папку приложения, поэтому сжатие ему только на пользу.
- Пакет, подписанный другим ключом, игнорируется целиком.
- Раскладки из пакета приходят выключенными: их включают в настройках
  клавиатуры.
- Установка и удаление пакета подхватываются на лету — клавиатура слушает
  события о пакетах `com.ai10.k12kb.lang.*`.
